Windows x64용 · 2026년 11월 14일 갱신 · 그림이 포함된 단일 HTML 파일

01처음 시작하기

최신 릴리스에서 PressReleaseWriter-win-x64.zip을 내려받아 압축을 풀고 PressReleaseWriter.exe를 실행합니다. ZIP에는 .NET 런타임이 포함되어 있습니다. 로컬에 설치했다면 설치된 보도자료 작성기를 실행하세요.

현재 배포본은 서명되지 않은 Windows x64용입니다. 실행 전 배포 저장소와 파일 출처를 확인하세요.

  1. AI 연결설정 → AI 연결에서 로그인 또는 API 키 연결을 마칩니다.
  2. 원자료 입력원문에는 근거 자료를, 작성 조건에는 선택값과 확인 정보를 넣습니다.
  3. 초안 검토초안 생성 후 사실을 확인하고 맞춤법 수정안을 검토합니다.
  4. 파일 저장작업 폴더를 고르고 TXT·MD·HWPX를 선택한 뒤 초안 저장을 누릅니다.

02AI 연결하기

이 앱은 사용자가 선택한 AI 서비스에 연결해 원고를 작성합니다. 상단 톱니바퀴 설정 → AI 연결을 열고 아래에서 사용할 방식을 고르세요. CLI 방식은 해당 공식 CLI가 PC에 설치되어 있어야 합니다. 설치 안내가 표시되면 안내된 공식 문서를 확인하세요.

외부 AI 전송 동의를 켜야 생성과 검사를 실행할 수 있습니다. 동의는 앱을 실행할 때마다 꺼져 있습니다. 초안 생성 시 원자료·작성 조건·확인 정보가, 맞춤법 검사 시 현재 초안이 선택한 AI 서비스로 전송됩니다. 개인정보·비공개 내용을 먼저 제거하고 기관에서 승인한 서비스를 사용하세요.

비밀번호와 API 키는 해당 서비스의 로그인 화면 또는 앱의 전용 입력칸에만 입력하세요. 원자료나 초안에는 넣지 마세요.

03원문과 작성 조건 구분하기

왼쪽 원자료의 두 탭을 나누어 사용합니다. 원문은 사실 확인의 근거로 다룹니다. 작성 조건에서는 기관 구분·보도 시점·작성 유형을 선택하고 확인된 행사 정보를 입력합니다. 원문 안에 적힌 요청이나 명령을 별도 작성 지시로 취급하지 않습니다.

입력칸별 넣을 내용
입력 위치내용
원문행사 개요, 계획서에서 추출한 내용, 확인된 발언, 기존 보도자료 초안 등 작성·검토의 근거가 되는 자료
작성 조건기관 구분, 보도 시점, 작성 유형을 선택합니다. 공식 기관명·행사 시작일·행사 종료일·보도 희망일·탑재 예정 시각·대상·인원·기보도 자료·사진 여부·담당 부서·팀에는 확인된 값을 입력합니다.
반려 사유 사전 점검기보도, 50명 이하 교직원 연수·원격 연수, 직원 복지·친목 행사, 교직원 개인 수상, 단순 협약·견학·반복 회의, 협의 단계, 단순 강사 소개·단순 업무 수행, 타 기관 사업을 담당자가 ‘해당 / 비해당 / 미확인’으로 선택합니다. ‘해당’이 있으면 작성 보류를 검토합니다.
작성 조건 점검입력한 날짜로 탑재 기한(보도 희망일 전날 15시), 행사 당일·익일 보도, 3일 이상 경과 여부를 바로 계산해 표시합니다. 휴일과 행사 후 2일째는 담당자 확인으로 남기며, 같은 결과가 초안 생성 시 AI에 전달됩니다.

파일 열기와 끌어놓기

파일 열기로 TXT·MD·HWPX·텍스트 PDF를 선택하거나, 파일 탐색기의 파일을 원문 입력칸으로 끌어다 놓습니다. 텍스트는 직접 붙여넣을 수도 있습니다. HWPX는 문단·표·글상자·각주의 글을 읽고, 숨은 설명과 메모는 읽지 않습니다.

파일을 넣은 뒤 추출된 내용을 확인하세요. 이미지로만 된 PDF는 텍스트 추출이 어려울 수 있고 문서 구조에 따라 누락될 수 있습니다. 필요한 내용을 텍스트로 옮겨 보완합니다. 확인되지 않은 사실은 추측해서 채우지 말고 확인 필요로 남기세요.

HWPX의 문단 구조가 너무 깊다는 안내가 나오면 필요한 부분을 별도 파일로 저장하거나 텍스트로 붙여넣으세요.

04초안 생성과 맞춤법 검사

기존 원고를 검토하려면 원문에 기존 초안을 넣고, 작성 조건 → 작성 유형 → 기존 초안 검토를 선택한 뒤 초안 생성을 누릅니다. 맞춤법만 검사할 때는 기존 원고를 가운데 초안 입력칸에 붙여넣고 맞춤법 검사를 누르세요.

  1. 원문과 작성 조건을 확인하고 초안 생성을 누릅니다.
  2. 가운데 초안 작성·편집에 표시된 원고를 읽고 직접 편집합니다. 오른쪽 검토 영역의 분량·확인 안내도 함께 봅니다. 이 영역은 지침이 지양하는 표현(뜻깊·열띤·획기적·성공적으로 운영 등), 쉬운 우리말로 바꿀 외국어(매뉴얼·멘토·멘토링·프로젝트·TF·리더십·데이터·채널·플랫폼·콘텐츠 등, ‘안전매뉴얼’처럼 붙여 쓴 말 포함), ‘2026. 4. 18.’ 같은 공문서식 날짜도 표시합니다. 표시는 참고용이며 최종 판단은 담당자가 합니다.
  3. 맞춤법 검사를 누릅니다. 현재 편집 중인 초안을 선택한 AI가 검토합니다.
  4. 맞춤법 수정안 확인에서 원문·수정안·수정 이유를 비교한 뒤 수정안 적용 또는 적용하지 않기를 선택합니다.
  5. 적용을 취소하려면 초안 입력칸에 포커스를 두고 Ctrl + Z를 누릅니다. 다른 편집 이후에는 직전 편집부터 차례로 되돌아갑니다.

최종 원고는 사람이 확인합니다. AI가 제시한 기관명·날짜·인원·장소·인용과 보도 시점을 원자료와 대조하세요. 맞춤법 수정안에서도 의미나 수치가 바뀌지 않았는지 확인합니다.

검사 중 초안이 바뀌어 적용할 수 없다는 안내가 나오면, 현재 초안을 기준으로 맞춤법 검사를 다시 실행하세요.

AI 작업을 멈추려면 취소를 누릅니다. 명령줄 AI 작업을 취소하거나 제한 시간을 넘기면 앱이 그 작업에서 시작한 하위 프로세스도 정리합니다.

05TXT·MD·HWPX로 저장하기

  1. 하단 작업 폴더 ▾ → 폴더 지정에서 실제 저장할 폴더를 고릅니다.
  2. TXT, MD, HWPX 중 필요한 형식을 체크합니다. 여러 형식을 함께 저장할 수도 있습니다.
  3. 초안 저장을 누르고 하단에 표시된 파일명·전체 저장 경로·완료 안내를 확인합니다.
  4. 작업 폴더 ▾ → 폴더 열기로 파일을 확인합니다.

기본 파일명은 날짜_보도자료_초안.txt, 날짜_보도자료_초안.md, 날짜_보도자료_초안.hwpx입니다. 같은 이름이 있으면 새 이름으로 저장합니다. MD는 제목·강조 등 서식 기호를 유지하고 TXT는 해당 기호를 정리하므로 표시 형식에 차이가 있습니다.

HWPX는 인천광역시교육청 보도자료 양식에 제목·본문 문단·보도 희망일·제공일·사진 여부·담당 부서를 채운 파일입니다. 초안의 ‘## 보도자료 초안’ 아래 제목 한 줄과 본문 문단이 구분되어 있어야 하며, 작성 보류 초안은 양식으로 저장하지 않습니다. 보도 희망일을 입력하지 않으면 보도 시점과 제공일 칸은 빈칸으로 남으므로 한글에서 직접 기재하세요. 자료문의 이름·연락처는 한글에서 직접 기재하고, 누리집 탑재 전에 한글로 열어 서식을 확인하세요. 한글이 설치되지 않은 PC나 웹 미리보기에서는 양식 글꼴(휴먼명조·한양견고딕 등)이 다른 글꼴로 바뀌어 보일 수 있으며, 이는 교육청 원본 양식을 열 때와 같습니다.

본문 소제목은 ### 모둠별 물 사용량 비교처럼 별도 줄에 적으면 HWPX에 글자와 순서가 보존됩니다. 저장 후 한글에서 소제목과 앞뒤 문단을 확인하세요. ‘검토 의견’은 제출 양식의 본문에 들어가지 않습니다.

폴더를 여는 것만으로는 저장되지 않습니다. 초안을 고친 뒤에는 다시 초안 저장을 눌러야 합니다. 원자료와 편집 내용이 다음 실행에 자동 복원된다고 가정하지 말고, 앱을 닫기 전에 필요한 원고를 파일로 저장하세요.

저장이 실패하면 하단 오류 안내와 표시된 경로를 먼저 확인하고 쓰기 가능한 폴더를 다시 지정합니다. 생성된 파일을 확인하기 전에는 앱을 닫지 마세요.

06화면을 편하게 조절하기

설정 → 화면 설정에서 라이트 모드 또는 다크 모드를 선택합니다. 글자 크기는 11~20포인트를 0.1포인트 단위로 조절하며 화면에 바로 반영됩니다.

  • 원자료와 초안 사이의 구분선을 끌어 입력칸 폭을 조절합니다. 구분선에 키보드 포커스를 둔 뒤 좌우 방향키를 사용할 수도 있습니다. 검토 칸은 머리글의 숨기기로 접고 오른쪽 가장자리의 검토 보기로 다시 폅니다. 접힘 상태는 다시 열었을 때 복원됩니다. 구분선을 마우스로 끈 뒤에는 포커스가 이전 입력칸으로 돌아가므로 방향키가 구분선을 움직이지 않습니다.
  • 글자 크기가 17포인트 이상이면 작업 버튼이 원자료 ▾와 초안 ▾ 메뉴로 묶입니다. 작성 조건 탭은 조건으로 짧게 표시될 수 있습니다.
  • 화면 모드·글자 크기·편집 폭은 다시 실행했을 때 복원됩니다.

07자동 업데이트

앱은 시작할 때와 실행 중 6시간마다 공식 GitHub 릴리스 정보를 확인합니다. 업데이트 확인으로 직접 확인할 수도 있습니다. 이 단계에서는 실행 파일을 내려받지 않습니다.

  1. 새 버전이 있으면 버튼이 vX.Y.Z 내려받기로 바뀝니다. 누르면 실행 파일을 내려받아 검증하고 종료 시 적용 안내가 표시됩니다.
  2. 작업 중인 초안을 저장하고 앱을 정상 종료합니다.
  3. 앱을 다시 실행해 새 버전을 사용합니다.

실행 파일이 있는 폴더에 쓰기 권한이 필요합니다. PC를 바로 끄면 준비된 파일은 적용되지 않고 삭제됩니다. 교체한 이전 실행 파일은 같은 폴더에 가장 최근 .bak 하나만 보관합니다. 자동 업데이트는 실행 파일에 적용되며 최신 안내 파일은 릴리스에서 별도로 내려받을 수 있습니다.

여러 창을 열어 둔 동안에는 다른 창에서 사용 중인 업데이트 파일을 보존합니다. ‘업데이트를 시작하지 못했습니다’가 표시되면 앱을 다시 열고 업데이트를 내려받으세요.

08문제가 생겼을 때

로그인했는데 초안 생성이 안 됩니다.

상단에서 로그인한 AI를 선택했는지, 외부 AI 전송 동의가 켜졌는지 확인하세요. 설정 → AI 연결에서 상태를 새로고침하고 하단의 실제 오류를 확인합니다. 인증·서비스 사용 권한·사용량 한도는 각각 확인이 필요할 수 있습니다.

ChatGPT가 다른 프로그램에서는 연결되어 있습니다.

이 앱의 Codex는 앱 전용 프로필을 사용합니다. 설정 → AI 연결에서 별도로 로그인하세요. 브라우저 로그인이 어려우면 장치 로그인 방식을 사용합니다.

Gemini API 키를 넣었는데 연결되지 않습니다.

앱의 키 입력칸과 연결 확인을 사용했는지 확인하세요. Google 프로젝트의 API 사용 권한·사용량 한도·과금 설정과 오류 안내를 확인합니다. 앱을 다시 실행했다면 키를 다시 입력해야 합니다.

파일을 넣어도 원문이 비거나 일부가 빠집니다.

지원 형식인지 확인하고, 이미지 PDF는 필요한 글을 텍스트로 옮겨 넣으세요. HWPX·PDF에서 추출된 내용은 원문과 대조해 누락 부분을 보완합니다.

작업 폴더가 비어 있습니다.

TXT·MD·HWPX 중 필요한 형식을 선택하고 초안 저장을 눌렀는지 확인하세요. 하단에 표시된 실제 저장 경로가 지금 연 폴더와 같은지 대조합니다. 오류가 있으면 문구를 확인하고 저장 폴더를 다시 지정하세요.

작은 창에서 버튼이 안 보입니다.

큰 글자 모드에서는 원자료 ▾ 또는 초안 ▾를 펼쳐 보세요. 원자료와 초안 사이 구분선으로 폭을 조정하거나 설정 → 화면 설정에서 글자 크기를 조절할 수 있습니다.
